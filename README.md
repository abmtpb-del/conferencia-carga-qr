# Conferência de Carga por QR Code

Projeto web destinado a facilitar a conferência de materiais e bens patrimoniais utilizando QR Codes e a câmera do celular.

## Objetivo

Permitir que o usuário acesse a relação de materiais de uma seção, escaneie os QR Codes dos itens e acompanhe o resultado da conferência de maneira simples e organizada.

## Fluxo planejado

1. Selecionar ou acessar uma seção por meio de QR Code.
2. Visualizar a relação de materiais cadastrados.
3. Abrir a câmera do celular.
4. Escanear o QR Code de cada material.
5. Marcar automaticamente os materiais localizados.
6. Identificar itens pendentes, não encontrados ou divergentes.
7. Gerar um resumo da conferência.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Leitura de QR Code pela câmera
- Arquivos JSON para armazenamento inicial dos dados
- GitHub para versionamento
- GitHub Pages para publicação da versão web

## Situação do projeto

O projeto encontra-se em fase inicial de desenvolvimento e organização da estrutura.

## Segurança

Informações institucionais, dados pessoais, números de identificação e dados patrimoniais sensíveis não devem ser publicados em repositórios públicos.
